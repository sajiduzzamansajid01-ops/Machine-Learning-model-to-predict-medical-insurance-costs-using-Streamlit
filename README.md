# Insurance Cost Estimator

An end-to-end Machine Learning web application that predicts annual health insurance charges based on a patient's demographics and lifestyle.

## Project Overview
- **Data:** Medical Cost Personal Datasets (2,772 records).
- **Exploratory Data Analysis (EDA):** Handled skewness using log transformation, created BMI categories, and engineered features.
- **Modeling:** Trained Linear Regression, Random Forest, and Gradient Boosting models. 
- **Best Model:** Random Forest Regressor (R² Score: **85.7%**).
- **Deployment:** Built an interactive UI using Streamlit.

## Technologies Used
- Python
- Pandas & NumPy (Data Manipulation)
- Scikit-Learn (Machine Learning)
- Matplotlib & Seaborn (Data Visualization)
- Streamlit (Web App Deployment)
